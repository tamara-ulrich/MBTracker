# App Store Description — MBTracker

## Name
MBTracker

## Subtitle
Mandarin Blueprint Study Tracker

## Description
MBTracker helps Mandarin Blueprint learners track their daily study time and maintain the correct balance across activity types.

Start a timer for each activity — Build, Get, Activate, or Immerse — and MBTracker shows you in real time whether your ratios are on target. When you finish a Build session, log the last character you completed to track your progress through the MB curriculum.

**Features:**
- Track time across all four MB activity types (Build, Get, Activate, Immerse)
- Real-time ratio display with colour-coded feedback (green = on target)
- Character progress tracking — log your last completed character after each Build session
- Edit past sessions to correct mistakes or add forgotten entries
- Statistics screen with 7-day, 30-day, and all-time summaries
- Daily breakdown showing time per activity and characters learned
- Level history showing your progress through MB levels
- CSV export for daily data and level history
- Timer persists across app restarts
